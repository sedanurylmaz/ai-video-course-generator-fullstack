# AI Video Course Generator

An AI-powered full-stack platform that automatically generates structured video courses using Large Language Models. The system creates course outlines, generates educational content, and helps users build complete learning materials with AI assistance.

## Features

- 🤖 AI-powered course generation
- 📚 Automatic course outline creation
- ✍️ AI-generated educational content
- 🎥 Video course structure generation
- 🌐 Full-stack web application
- 🔐 User authentication
- 📱 Responsive UI
